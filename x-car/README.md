# X-CAR — Intelligent Electric Mobility

Website konsep X-CAR untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama, CSS dan JavaScript responsif dalam satu file.

## Preview
Setelah GitHub Pages aktif, halaman tersedia di:
https://risetabajoo.github.io/x-car/

## Catatan konten
X-CAR dan NOVA/VOLT/URBAN merupakan konsep. Spesifikasi, harga, garansi, sertifikasi, ketersediaan, dan dealer belum diverifikasi. Formulir hanya validasi demo di browser dan belum mengirim data ke server.

## Deployment
Letakkan folder `x-car` di root repository `risetabajoo/risetabajoo.github.io`. Pastikan GitHub Pages menerbitkan branch `main` dari root.
